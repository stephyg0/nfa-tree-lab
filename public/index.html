DFA · NFA · PDA

DFA

Exactly one transition for each state and alphabet symbol. No ε-moves. Add a dead state for otherwise missing transitions.

NFA

Zero, one, or many transitions per symbol. ε consumes nothing. A string accepts if any branch reads all input and ends in a final state.

PDA

Labels are input, pop → push. ε skips that operation. The stack starts empty; its top is on the left. Accept by final state after all input is read.
